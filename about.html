A browser retro-game player built on EmulatorJS 4.3, running entirely from local files. It adds a pause menu, save slots, picture controls, a performance helper, a game library, an illustrated guide and ten use-case pages. What's new

Open-source software

  • EmulatorJS – GNU GPL v3. The player in data/src/.
  • Emulator cores – built from the RetroArch / libretro projects. Each core has its own licence (GPL, LGPL, MIT, BSD and others; a few are non-commercial). Full list: THIRD-PARTY-NOTICES.md.
  • 7-Zip decompression for core files, and the other small libraries listed in the notices file.
