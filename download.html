Check your download

Every release has a SHA256SUMS.txt file. Compare it with your download: Windows certutil -hashfile FILE SHA256, macOS and Linux shasum -a 256 FILE.

Installers that are not signed with a paid certificate make Windows and macOS show a warning the first time. That is expected for a community build; the checksum proves the file is the one the publisher built.
