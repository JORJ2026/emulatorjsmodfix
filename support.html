Help and support

Common problems

No sound

Click or tap the game once (browsers block sound until you do). Check F9 (mute) and the per-game volume in the F1 panel.

A game shows a black screen

Open the game info box and switch core, or press F1 and check the notices list. Make sure the file is for the system you chose.

It is slow or stutters

Press Shift+F9 to lower the performance mode, or use the speed test in the F1 panel. Turn on hardware acceleration in your browser settings.

PSP, DOS or 3DS games do not start

These cores need threaded WebAssembly. Reload the page once, use a current Chrome, Edge or Firefox, and open the page from https or localhost.

My saves disappeared

Saves live in this browser. Clearing site data, private browsing, or a different browser or device starts empty. Export your options and save files regularly.

The installed app shows an old version

Close and reopen it twice. The app updates itself in the background; the second open uses the new files. The About page shows the version.

A Windows or Mac warning appears

Unsigned community builds trigger it. Compare the file with SHA256SUMS.txt on the release page, then choose Run anyway (Windows) or right-click, Open (Mac).

Game Boy Advance, SNES or other cores say "Error downloading core"

The core files in data/cores/ are missing on this copy of the site. See the status page.

Report a problem

Use Report a problem in the F1 panel (Install and downloads), or open the issue form. Please say what you did, what you expected and what happened. Do not attach game files.
